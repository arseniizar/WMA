# WMA - Computer Vision & Machine Learning Labs

This repository contains Python implementations for advanced computer vision and machine learning laboratories using OpenCV, TensorFlow, and Ultralytics (YOLO).

## Repository Structure

| Lab | Topic | Description |
|-----|-------|-------------|
| [lab1](./lab1) | Object Tracking | Red object detection & tracking using color spaces. |
| [lab2](./lab2) | Image Processing | Coin detection & tray analysis using Hough transforms. |
| [lab3](./lab3) | Local Descriptors | Object recognition & tracking via ORB/SIFT descriptors and Homography. |
| [lab4](./lab4) | Optical Flow | Feature point detection (Shi-Tomasi) and tracking (Lucas-Kanade). |
| [lab5](./lab5) | CNN Classification | Fruit image classification using a custom Convolutional Neural Network. |
| [lab6](./lab6) | YOLO Detection | Object detection and custom dataset fine-tuning utilizing YOLOv8. |
| [lab7](./lab7) | Vision Transformers | Comparative analysis of local CNNs vs global Vision Transformers (ViT). |

## Requirements & Setup

This project is optimized for Python 3.11. To install all required dependencies across all labs, run:

```bash
pip install opencv-python numpy tensorflow matplotlib scikit-learn ultralytics tensorflow-hub
```
